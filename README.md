# tws-scripts

Small, narrowly scoped utilities for Interactive Brokers Trader Workstation (TWS).

## Tools

### vwce

Read-only VWCE session status, daily trading-window progress, and historical price medians for the last 30 completed IBIS2 trading sessions. See [the status command](vwce-buy/README.md#vwce-status).

### vwce-buy

Safe CLI for submitting one directly routed VWCE limit order. See [its documentation](vwce-buy/README.md).
